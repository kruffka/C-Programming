# 9_git

- Зачем нужен Git и чем он отличается от GitHub
- Установка и настройка: вход в GitHub через gh, SSH или токен
- Репозиторий: init, clone
- Состояния файлов: add, commit, status, diff, log, blame
- .gitignore и секреты в истории
- Удаленный репозиторий: push, pull, fetch
- Ветки, merge, конфликты, rebase
- Pull request и merge request: код-ревью, squash-merge, fork
- Отмена изменений: restore, revert, reset, reflog
- Open source: fork, PR, лицензии, good first issue
- Версия в бинарнике, stash, gh CLI, git-lfs, Hugging Face, GitLens
