# Задание под звездочкой: Git

## Как начать

```bash
git clone -b git_task_2026 --single-branch --depth 1 https://github.com/kruffka/C-Programming.git git_star
cd git_star
bash setup.sh
cd broken-repo
bash check.sh
```

Windows: все команды - в Git Bash (он ставится вместе с Git и есть в меню "Пуск"), в cmd и
PowerShell `bash` не сработает. Скрипт сам выберет, чем распаковать: `unzip`, `python` или
PowerShell, так что доустанавливать ничего не нужно.

`setup.sh` просто распаковывает архив: рядом появится папка `broken-repo` - готовый
git-репозиторий вместе с историей и папкой `.git`. Если скрипт не сработал, распакуйте
`broken-repo.zip` вручную.

`check.sh` собирает проект, гоняет тесты и показывает, что в репозитории не так. Запускается
в терминале, на Windows - в Git Bash.

## Задание

Здесь кто-то навел беспорядок:

1. **Незавершенный merge** - конфликт в `src/sort.c` никто не разрешил.
2. **Удаленная ветка** `feature` - в ней было два коммита, ветку удалили, и теперь
   `git branch` ее не показывает.
3. **Коммит без ветки** - `fix: защита от пустого массива` сделан, когда HEAD не стоял
   ни на одной ветке; сейчас на него не указывает ничего.
4. **Отладка в истории** `main` - в `src/main.c` закоммичен `printf("debug: ...")`,
   это надо убрать, не переписывая историю.

## Цель

`bash check.sh` должен напечатать "ВСЕ НА МЕСТЕ". Скрипт сам проверяет, что все завершено:
собирает проект, гоняет тесты и смотрит состояние репозитория. Что именно он смотрит - видно
в `check.sh`, он короткий.

Начинайте с merge: пока он не завершен, коммитить не даст.

## Правила

- Историю `main` не переписывать: никаких `reset --hard` на `main` и `push --force`.
- Ветку `feature` вернуть с двумя коммитами, висящий коммит сохранить в новой ветке `rescue`.
- Перед первым коммитом проверьте, что Git знает вас: `git config --global user.email`.

## Сдача

Покажите, что `bash check.sh` печатает "ВСЕ НА МЕСТЕ", и объясните, что произошло и какими
командами починили. Заливать репозиторий к себе не обязательно, достаточно показать локальную версию.
